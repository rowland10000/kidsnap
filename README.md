# KidSnap 記得拍

把同一個孩子不同時期的照片丟進來，它會自動找出他、把臉對齊到同一個位置，串成一段看著長大的影片。

全程在你自己的電腦裡跑。沒有帳號、沒有雲端、沒有費用，照片不會上傳。

macOS 12 以上 · 免費

---

## 下載

到 [Releases](../../releases/latest) 取得最新版，兩個檔案選一個：

| 檔案 | 適用 |
|---|---|
| `KIDSNAP_release.zip` | Apple Silicon（M 系列晶片） |
| `KIDSNAP_release_intel.zip` | Intel |

不確定自己是哪一種：點左上角蘋果選單 →「關於這台 Mac」，「晶片」寫 Apple M 開頭的選第一個，寫 Intel 的選第二個。

### 檢查檔案

想確認下載到的跟我發布的是同一份，在終端機跑：

```
shasum -a 256 ~/Downloads/KIDSNAP_release.zip
```

v1 的結果應該是：


## 安裝

1. 解壓縮下載到的 zip，得到一個名為 `KIDSNAP` 的資料夾（檔名是英文全大寫）。放哪裡都可以，之後搬動或改名也沒問題
2. 打開資料夾，雙擊 `KIDSNAP.command`
3. 第一次會跳出一個黑色視窗做準備，約 40 秒
4. 瀏覽器會自己打開操作畫面。之後每次都是雙擊同一個檔案

需要的程式都已經附在檔案裡，不用另外裝任何東西。裝好之後關掉網路也能用。

## 第一次會跳出警告，這是正常的

我沒有買 Apple 開發者憑證做簽章，所以第一次打開時 macOS 會說「無法打開，因為來自未識別的開發者」或「Apple 無法檢查是否含有惡意軟體」。這不代表檔案有問題，你可以用上面的 SHA-256 自己確認。

放行步驟（只要做一次）：

1. 在警告視窗按「好」
2. 打開「系統設定」→「隱私權與安全性」→ 往下捲到「安全性」，會看到「已阻擋 KIDSNAP.command」
   （macOS 12 的路徑是「系統偏好設定」→「安全性與隱私權」→「一般」→「強制打開」）
3. 按「仍要打開」→ 在「確定要打開嗎？」視窗按「打開」。較新的 macOS 會要求輸入電腦密碼

之後再雙擊就不會再問。

## 怎麼用

1. 把照片一次全選丟進來，一次最多 150 張
2. 它會依拍攝日期排序，偵測每張照片裡的臉，沿著時間接力認出主角，再旋轉、縮放、裁切到同一個位置，最後統一亮度與膚色
3. 認不出或拍得太糊的會被排到最後並標明原因，不會進到影片裡
4. 對齊好的照片以卡片排出來，想改順序直接拖拉
5. 選速度與格式（MP4 或 GIF），輸出

## 隱私

照片不會上傳、不連任何伺服器、不需要帳號或金鑰。操作畫面的網址是 `127.0.0.1`，那是你自己的電腦。

## 已知限制

- 一次最多 150 張
- 支援 JPG、PNG、HEIC
- 只有 macOS，沒有 Windows 版
- 兄弟姊妹長得像的時候可能認錯
- 0 到 2 歲的照片還沒實際測過

## 維護承諾

這是我自己要用才做的工具，放出來給有同樣需求的人。它不需要伺服器，所以就算我哪天不維護了，你手上那份一樣能用。

有問題可以開 [Issue](../../issues)。
